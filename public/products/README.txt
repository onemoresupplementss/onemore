Product photos go in this folder (one .webp per product, named after its Group).

EASIEST (on a computer with this project):
1. Take a photo of the tub on a plain white sheet in daylight, front label facing the camera.
2. Name the file after the product's Group - the part after /p/ in its web address.
   Example: https://onemore.in/p/optimum-nutrition-serious-mass/ -> optimum-nutrition-serious-mass.jpg
3. Put your photos in one folder and run:   npm run photos -- "C:\path\to\folder"
   It trims, squares and compresses each photo into this folder as <group>.webp.
4. Type <group>.webp in the Image column of the Products sheet (all sizes of that product),
   commit the new files to GitHub, and tick PublishNow in Settings.

FROM A PHONE ONLY:
Make the photo square, under 150 KB, named as above (.webp, .jpg or .png), upload it here on
GitHub (Add file -> Upload files) and type the file name in the Image column.

You can also paste a full https:// image link into the Image column instead.

NOTE: some photos here came from the brands' own websites. Replace them with your own shelf
photos when you can - they show your real stock and the Indian importer sticker.
